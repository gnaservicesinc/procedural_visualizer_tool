# Scene Morph translation review

Reviewed 2026-09-07 against the 17 new English messages in `LiveWorkspace`.

French and German cover the panel, scene selectors, fader and endpoint
accessibility labels, capture action, status readouts, and help text.
Review checked natural phrasing, consistency with existing Live/scene vocabulary,
the distinction between temporary performance state and saved scenes, the exact
50% switching rule, skipped targets, and the fact that selecting a scene alone
does not change the output. All positional placeholders are preserved.

French uses *morphing de scènes* and *curseur*; German uses *Szenen-Morphing*
and *Regler*, with *Überblendung* in action and status text. Artist-authored scene
names remain untranslated. Automated catalog checks validate source coverage
and placeholders; GUI smoke checks exercise the translated workflow.
